# Haseeb Ali — Creative Portfolio Website

A single-page, dark-themed creative portfolio website for **Haseeb Ali** (Graphic Designer & Video Editor, Islamabad, Pakistan). 

Designed with a moody black-and-deep-maroon color palette, oversized bold display typography, thin red accent lines, circular icon badges, glassmorphic cards, and an interactive project modal lightbox.

---

## 🎨 Visual Identity & Palette
- **Background**: Deep Void Black (`#0a0809` to `#120e10`) with multi-layered glowing maroon radial halos.
- **Hero Display Typography**: Warm Cream Ivory (`#f4ece1`) using `Bebas Neue` and `Syne`.
- **Accents & Borders**: Crimson Red (`#e63946`) with glowing hover states and status pulse dots.
- **Cards**: Dark glassmorphic panels with micro-blur backdrop.

---

## 🚀 Sections
1. **Header & Top Status**: `[CREATIVE PORTFOLIO]` and `AVAILABLE FOR FREELANCE & ROLES` live pulsing status badge.
2. **Poster Hero Section**: Giant condensed `"PORTFOLIO"` display typography, 3-column editorial layout, rotating emblem badge, and stat counters.
3. **What I Do**: 5 service cards (Graphic Design, Video Editing, Promotional Banners, Layout & Editorial, Product Creatives).
4. **My Process**: 5-step numbered workflow timeline (01 Brief & Research → 05 Final Delivery).
5. **Featured Work**: Interactive project showcases with modal lightboxes (Levensa E-Commerce, Fitness Magazine, RainAware Campaign, Water Crisis Documentary).
6. **About Me & Tools**: Portrait photo, core designer traits, software badges (Photoshop, Premiere Pro, Canva, Illustrator, After Effects, Figma), and client testimonial.
7. **Let's Collaborate (Footer)**: 1-click email copy button, phone, location, custom SVG QR code cards for LinkedIn and Behance.

---

## 🛠️ Built With
- **HTML5** (Semantic Architecture)
- **CSS3** (Custom Properties, Glassmorphism, Flexbox & Grid, CSS Keyframe Animations)
- **Vanilla JavaScript** (Modal Lightboxes, Clipboard API, UI Micro-interactions)
- **Google Fonts** (`Bebas Neue`, `Cinzel`, `Plus Jakarta Sans`, `Space Mono`, `Syne`)

---

## 💻 Running Locally
Clone the repository and open `index.html` in any web browser:
```bash
git clone https://github.com/faizfalki999/Haseeb-s-Portfolio.git
cd Haseeb-s-Portfolio
```
Or start a local development server:
```bash
# Python
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
